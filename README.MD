# Teste Desenvolvedor Mobile Júnior - SEMEQ 2026
Este projeto foi feito como teste para a vaga de Desenvolvedor Mobile Júnior da empresa SEMEQ, em março/2026.

O projeto foi feito inteiramente em Kotlin utilizando o Android Studio. Foi utilizado arquitetura MVVM para desenvolvimento do projeto.

## Tecnologias utilizadas
- Android Studio 2024.2.2 (Ladybug Feature Drop)
- Biblioteca OkHttp para requisições para a API
- Kotlin Coroutines (viewModelScope) para execução da requisição fora a thread principal
